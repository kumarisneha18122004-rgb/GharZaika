DAILY FOOD ORDERS

🍽️ Food Ordering Dashboard

Agar aapko apni pasand ka food order karna hai, to Food Ordering Dashboard aapke liye hai. Yahan menu, prices, cart aur order ki details check kar sakte hain.

Is dashboard mein kya milega?

  • ✓ Food Menu: available food items aur unki prices dekhein.
  • ✓ Cart & Bill: items add karein, quantity change karein aur total amount check karein.
  • ✓ Payment: dashboard mein available Cash aur UPI payment options dekhein.
  • ✓ Track Order: Order ID enter karke order status check karein.
  • ✓ AI Food Assistant: food category ke according suggestions lein.
  • ✓ Regular Customer Discount: eligible customers ko 5% discount, maximum ₹50 tak, mil sakta hai.
Order karne se pehle: menu mein current availability aur prices check karein. Discount eligibility system ke rules par depend karti hai.

EVENTS & SPECIAL OCCASIONS

🎉 Catering Booking Dashboard

Birthday, family function, party ya kisi special event ke liye catering chahiye? Catering Dashboard par event ki details aur available package information submit karein.

Is dashboard mein kya milega?

  • ✓ Event Details: event type aur date enter karein.
  • ✓ Catering Packages: dashboard mein available packages aur unki prices check karein.
  • ✓ Guest Count: kitne logon ke liye catering chahiye, woh enter karein.
  • ✓ Estimated Amount: package price aur guest count ke according estimate dekhein.
  • ✓ Event Location: venue address aur special requirements share karein.
  • ✓ Payment Choices: available options mein 25% advance ya 100% full payment check karein.
Important: booking request submit karna final confirmation nahi hai. Payment aur booking status admin ki verification aur confirmation par depend karega.

SIMPLE PROCESS

Kaise Kaam Karta Hai?

Dono services ka process alag hai. Apni requirement ke according neeche diye gaye steps follow karein.

🛒

Food Order Karne Ka Tarika

  1. 1 Food menu mein items aur unki prices check karein.
  2. 2 Pasand ke food items cart mein add karein aur quantity select karein.
  3. 3 Order place karne se pehle items aur total bill carefully check karein.
  4. 4 Available payment option choose karke dashboard ke instructions follow karein.
  5. 5 Order ID save rakhein. Order status check karne ke liye isi ID ka use karein.
🎊

Catering Book Karne Ka Tarika

  1. 1 Apne event ke according available catering package select karein.
  2. 2 Event date, guest count, venue aur contact details enter karein.
  3. 3 Estimated amount aur payment options ko dhyan se check karein.
  4. 4 Booking request submit karein aur dashboard par diye gaye payment instructions follow karein.
  5. 5 Admin ki verification aur confirmation ka intezaar karein. Zaroorat par contact karein.
📢 Important Catering Delivery Notice: Regular home delivery available nahi hai. Bulk catering orders ke liye delivery sirf bahut zaroori situation mein aur availability ke according consider ki ja sakti hai. Otherwise, customer ko order khud collect karna hoga ya kisi doosre person ko collect karne ke liye bhejna hoga.
PAYMENT INFORMATION

Payment Ko Samjhein

Food orders aur catering bookings ke payment rules alag ho sakte hain. Payment karne se pehle apne dashboard par dikhaye gaye instructions check karein.

💵

Cash Payment

Food order ya catering booking ke liye Cash option tabhi select karein jab woh dashboard mein available ho. Dikhaye gaye payment instructions follow karein.

📲

UPI / QR Payment

Agar UPI option available ho, to dashboard mein diye gaye payment details ko carefully check karein. Payment complete hone ke baad proof sambhal kar rakhein.

🧾

Catering Advance

Catering mein available plan ke according 25% advance aur baaki 75% baad mein, ya 100% full payment ka option ho sakta hai.

Yaad rakhein: UPI QR scan karna apne aap payment confirmation nahi hota. Payment ka status verify hone aur admin ki confirmation milne tak catering booking ko confirmed na maanein. Final amount aur payment instructions dashboard par check karein.
