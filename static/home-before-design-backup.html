🍴 Food Order Kaise Karein?

Normal Food Ordering — Step by Step

  1. Food Dashboard button par click kijiye.
  2. Menu mein dishes, pictures aur prices dekhiye.
  3. Apni pasand ki dishes cart mein add kijiye.
  4. Quantity aur order details check kijiye.
  5. Apna naam, phone number aur maangi gayi details bhariye.
  6. Available payment option, jaise Cash ya UPI, choose kijiye.
  7. Order submit karke order ID aur status note kar lijiye.
  8. Order ready hone par pickup instructions follow kijiye.

📌 Food Order Ke Liye Zaroori Baatein

  • Order place karne se pehle prices aur quantity check karein.
  • Phone number sahi bharein, taaki order ke baare mein contact ho sake.
  • Payment ke liye dashboard par dikhaye gaye instructions follow karein.
  • Order ID ko sambhal kar rakhein.
Pickup Only: GharZaika ke is demo project mein home delivery available nahi hai. Food ko pickup karna hoga ya apni taraf se kisi ko collect karne bhejna hoga. Pickup se pehle location aur timing confirm karein.

🎉 Bulk Catering Booking Kaise Karein?

Bulk Booking — Step by Step

  1. Catering Dashboard open kijiye.
  2. Available catering packages aur unki prices dekhiye.
  3. Event type aur guests ki sankhya select kijiye.
  4. Event date aur event location bhariye.
  5. Apni special food requirements likhiye.
  6. Submit karne se pehle saari details check kijiye.
  7. Booking submit hone par booking ID aur status note kijiye.
  8. Payment ke liye sirf dashboard ya business ke verified instructions follow kijiye.

💰 Catering Payment Information

Project ke proposed payment plan mein:

  • 25% advance: Total estimated amount ka 25%.
  • 75% balance: Baaki 75% amount.

Example: Agar total amount ₹2,000 hai, toh proposed advance ₹500 aur remaining balance ₹1,500 hoga.

Important: Ye payment calculation ka demo hai. Online payment gateway aur payment verification alag se integrate karna zaroori hai. Sirf booking submit hone ka matlab advance payment successfully verify hona nahi hai. Booking status ko dashboard par check karein.

Note: Dish-wise bulk selection tabhi booking mein count hogi jab Catering Dashboard mein ye feature available aur connected ho. Food Dashboard ka normal order catering booking se alag hai.
